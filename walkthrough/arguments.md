Cppcheck works best for you if you set it up according to your needs. You may e.g. want to suppress certain kinds of warnings. This is done through the extension property `arguments`, with the different flags or arguments available being detailed in the Cppcheck manual ([open source](https://cppcheck.sourceforge.io/manual.pdf#page=4) / [Premium](https://files.cppchecksolutions.com/manual.pdf#page=4)). Separate arguments with spaces, e.g. `--suppress=missingInclude --inconclusive`.

The extension always runs cppcheck with `--enable=all`, so all checks are enabled. Use the severity filter or suppressions to reduce the number of warnings.

Cppcheck Premium works without extra setup, but Premium checks such as `--premium=misra-c-2023` have to be enabled in the arguments. The Premium checks are described in the [Premium manual](https://files.cppchecksolutions.com/manual.pdf#page=44).

The arguments can also be generated by a script, with the syntax `@(command)`. The extension expects the command to output the arguments wrapped with `@()`, e.g. `echo "@(--project=build/compile_commands.json)"`.

See [Configuration](https://github.com/cppchecksolutions/vscode-cppcheck-official#configuration) in the README for details.
